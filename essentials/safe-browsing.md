# Safe Browsing

The web browser is the primary tool we use to interact with the digital world, making it a primary target for attackers. Safe browsing habits are essential for protecting your data.

## Understanding HTTPS
When you visit a website, look for the padlock icon or `https://` in the URL.
- **HTTPS** ensures the connection between you and the website is encrypted. 
- **Important:** HTTPS does *not* mean a website is safe or legitimate. It only means the connection is secure. A malicious phishing site can still use HTTPS to securely steal your password!

## Spotting Malicious Links
Attackers frequently use deceptive links. Before clicking:
- **Hover to Discover:** Hover your mouse over a link (without clicking) to preview the actual destination URL.
- **Look for Typosquats:** Attackers register domains that look like real ones (e.g., `paypa1.com` instead of `paypal.com` or `google-support.com` instead of `google.com`).
- **Use Link Checkers:** If a link looks suspicious, you can use services like VirusTotal to scan it before opening.

## Browser Extensions and Security
Extensions can add great functionality, but they can also be massive security risks because they can read everything you do in the browser.
- Only install extensions from official stores.
- Limit the number of extensions you use.
- Be wary of extensions asking for permissions like "Read and change all your data on all websites."

## Ad Blockers
Using a reputable ad blocker (like uBlock Origin) isn't just about avoiding annoying ads; it's a critical security measure. "Malvertising" is a technique where attackers buy ad space on legitimate sites to distribute malware. Blocking ads blocks these attacks.
